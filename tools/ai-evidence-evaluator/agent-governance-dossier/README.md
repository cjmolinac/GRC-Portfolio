# Agent Governance Dossier — GRC AI Evidence Evaluator

A dossier built piece by piece, applying the role defined in CertiProf's **AI Agent Manager (AIAM)** body of knowledge to a tool I built: the [GRC AI Evidence Evaluator](../). The tool is treated as an agent — it reads evidence, calls a language model, and produces a score a third party might rely on — and is governed accordingly.

"Agent Governance Dossier" is my own name for the set; it is not a term defined by CertiProf.

## Status

| # | Piece | What it is | Status |
|---|---|---|---|
| 1 | [Identity sheet](01-agent-identity-sheet.md) | What the agent is, who owns it, what it can touch, when it is switched off | **Published** |
| 2 | Job description and operating procedure | What it may do, and the steps for the person using it | In development |
| 3 | Validation plan | Five pre-production tests, with their real status | In development |
| 4 | Register entry | The line in a central inventory of agents | In development |
| 5 | Control mapping | ISO/IEC 42001, ISO/IEC 27001, NIST AI RMF, EU AI Act | In development |
| 6 | Reproducibility test | Script that runs the same case several times and measures score variance | In development; not yet run on real models |

Each piece is added here once I have reviewed it.

## Limits

Single author; no independent review. The identity sheet's structure is adapted from the AIAM study guide; field names are my own. This is a personal portfolio piece, not an audit or a certification.
